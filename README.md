# Sur les traces de Raphy

Expérience web interactive mobile-first créée comme cadeau narratif pour Raphy.

## Version actuelle

Cette version est une reconstruction modulaire en HTML/CSS/JavaScript pur, pensée d'abord pour iPhone/Safari :

- code d'accès `060361` avec indice taquin ;
- ouverture et rencontre romancée ;
- 26 traces / scènes ;
- sauvegarde locale ;
- boutons Skip sur les séquences longues ;
- mini-jeux variés (timing, canvas tactile, logique, hidden-object, dialogues, escape game) ;
- 7 questions pour la scène dodo et 7 pour le super-héros ;
- gynécologue en 7 questions absurdes non graphiques ;
- numéro masqué avec `1105` ;
- grand escape game avec rappels de scènes antérieures ;
- procès de Mehdi réécrit sous forme de dossiers ;
- séquence horreur et option de passage ;
- final orienté futur avec cœur et « Je t’aime ❤️ » ;
- PWA / service worker ;
- zone de test cachée pour Mehdi.

## Confidentialité

Ce dépôt est public à la demande du propriétaire. Aucun média personnel n'est inclus dans cette version du dépôt. Le code d'accès ne constitue donc pas une vraie mesure de sécurité : le code source d'un dépôt public reste consultable.
